# Перевірено

Офлайн-пошук у перевірених навчальних фрагментах. Відповідь показується лише тоді, коли в базі є джерело, і завжди поруч із текстом цього джерела, його назвою та версією документа. Працює без інтернету й без мовних моделей (ШІ).

## Файли

Усі файли лежать в одній папці, без підпапок.

- `index.html`, `style.css`, `app.js` — інтерфейс.
- `search.js` — пошук за ключовими словами.
- `sources.json` — база фрагментів.
- `sw.js`, `manifest.webmanifest`, `icon-180.png`, `icon-512.png` — робота без інтернету та іконка на екрані «Додому».
- `tests.mjs` — автотести (`node --test`). На сайт не впливає.

## Як шукає

1. Запит ділиться на слова, службові слова («як», «при», «коли»…) відкидаються.
2. Слова зводяться до основи: «кровотечу», «кровотечі» і «кровотеча» — одне слово.
3. Загальні слова («допомога», «поліцейський», «застосування», «рука»…) самі нічого не знаходять.
4. Знайдено всі змістовні слова — «Знайдено джерело» з печаткою «Перевірено».
5. Знайдено частину — «Точного джерела немає», найближчий фрагмент і список слів, яких у ньому немає.
6. Нічого — «Джерела немає». Відповідь не вигадується.

Знайдені слова підсвічуються в тексті джерела, а під ним видно, де саме був збіг.

## Як додати фрагмент

Скопіюйте наявний фрагмент у `sources.json` і замініть поля:

- `id` — латиницею, без пробілів, унікальний;
- `discipline` — вид підготовки;
- `title` — коротка назва фрагмента;
- `document` — повна назва документа (номер, дата); конкретний порядок чи розділ — після « — »;
- `version` — чинність і редакція документа;
- `locator` — стаття, частина, пункт;
- `checked` — дата перевірки у форматі РРРР-ММ-ДД;
- `text` — абзаци фрагмента;
- `quote` — дослівна фраза з документа (можна залишити порожньою);
- `explanation` — пояснення простими словами, лише за текстом фрагмента;
- `keywords` — синоніми й розмовні слова, якими шукатимуть («жгут», «турнікет»).

Якщо в `sources.json` помилка, застосунок покаже, якого поля бракує.

## Оновлення

- Змінили лише `sources.json` — завантажте його на GitHub. Нова база підтягнеться, щойно буде мережа.
- Змінили інший файл — у першому рядку коду `sw.js` збільште версію (`perevireno-v1` → `perevireno-v2`) і завантажте обидва файли.

## Публікація з iPhone

1. Розпакуйте архів у «Файлах».
2. На github.com створіть репозиторій `perevireno` → Add file → Upload files → виберіть усі файли → Commit changes.
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Відкрийте сайт у Safari й дочекайтеся напису «Офлайн-копія готова».
5. «Поділитися» → «На екран Додому».

## Перевірка без інтернету

Увімкніть авіарежим, відкрийте застосунок з екрана «Додому» і введіть:

1. «Як зупинити сильну кровотечу з ноги?» — наказ МОЗ № 441, печатка «Перевірено».
2. «Коли можна стріляти без попередження?» — ст. 46 Закону «Про Національну поліцію»; нижче можна розгорнути ст. 43.
3. «Як надати допомогу при опіку?» — «Джерела немає».

## Джерела (перевірено 12.11.2026)

- Закон України «Про Національну поліцію» від 02.07.2015 № 580-VIII, чинна редакція від 12.04.2026: ст. 42 (ч. 7, 9), ст. 43, ст. 46.
- Наказ МОЗ України від 09.03.2022 № 441, зареєстрований у Мін’юсті 28.03.2022 за № 356/37692, поточна редакція — від прийняття: Порядок надання домедичної допомоги постраждалим при масивній зовнішній кровотечі.

Тексти фрагментів — стислий виклад положень; дослівно наведено лише поле `quote`. Перед заняттям звіряйте чинність на офіційному порталі «Законодавство України».
